# kaspol

Рабочая версия сайта «Каспий Полимер» по утверждённому инженерному эскизу из Claude.

## Реализовано

- строгий индустриальный дизайн на IBM Plex;
- адаптивная главная страница;
- отдельный каталог продукции;
- логистическая схема и этапы сделки;
- блок условий и оплаты;
- форма запроса коммерческого предложения;
- серверная валидация формы в `request.php`.

## Коммерческая логика

На сайте нет минимальной партии и нет публичного/скачиваемого прайса. Каталог содержит номенклатуру, а стоимость рассчитывается только в коммерческом предложении под конкретную заявку с учётом марки, объёма, текущей котировки, логистики и точки доставки.

## Форма

Адрес получателя задаётся на сервере переменной окружения:

```
KASPOL_FORM_TO=sales@example.ru
```

Обработчик проверяет обязательные поля, валидирует телефон и e-mail, использует honeypot против простых ботов и ограничивает частоту повторной отправки в рамках PHP-сессии.

## Перед публикацией

Контакты, реквизиты и название юридического лица из эскиза пока являются placeholders. Перед запуском нужно заменить их реальными данными заказчика, добавить реальные фотографии/документы и финальный текст политики обработки персональных данных.
